A hands-on SQL project focused on exploring remote job trends, salary patterns, and in-demand skills in the data analytics market.

## 🌟 Introduction
This project analyzes job data to answer practical questions about the data job market. Instead of looking at job postings at a surface level, the analysis goes deeper by combining salary information, company details, and required skills to understand what employers value most.

The main goal is to identify which roles pay the most, which skills are most commonly requested, and which skills tend to be associated with higher salaries.

## 🧭 Background
The dataset contains structured information about:
- 💼 job postings
- 🏢 companies
- 🛠️ skills associated with each role
- 💰 salary data
- 🏠 remote work availability

With this data, the project investigates how the market is shaped by technical skills and compensation trends. It is especially useful for understanding the demand for Data Analyst roles and the skill combinations that are most valuable.

### ❓ Questions this project helps answer
- Which jobs offer the highest annual salaries?
- Which skills are most demanded in remote Data Analyst positions?
- Which skills are linked to stronger earning potential?
- How do technical requirements vary across job listings?

## 🧰 Tools I used
- 🐘 PostgreSQL for creating the database and tables
- 🧾 SQL for querying, transforming, and analyzing data
- 📂 CSV files as the data source
- 🔗 JOINs to connect jobs, companies, and skills
- 🧠 CTEs and subqueries to organize analysis logic
- 📊 ORDER BY, GROUP BY, LIMIT, and aggregation functions for insights

## ✨ Project Highlights
### ✅ What I analyzed
- Highest-paying remote Data Analyst jobs
- Skills most frequently mentioned in job postings
- Average salary by skill
- Relationship between skill demand and compensation

### 📈 What the project reveals
- Salary trends in the remote data job market
- Most common technical requirements for Data Analyst roles
- Skills that appear to be most valuable to employers
- A clearer picture of which skills are worth learning and prioritizing

- Writing efficient SQL queries to answer business questions

## 🔄 Step-by-step workflow
1. Load raw data from CSV files into PostgreSQL tables.
2. Create relationships between companies, jobs, and skill data.
3. Filter remote Data Analyst job postings with valid salary data.
4. Rank jobs by salary to identify top-paying opportunities.
5. Join skills to job postings to determine demand.
6. Compare skill frequency with average compensation.
7. Summarize conclusions based on the findings.

## 🎯 Key outcomes
The analysis helps show which skills are most important in the current market and which combinations of skills are often linked to higher-paying Data Analyst roles. This turns the dataset into a practical guide for career planning and skill development.

## 🏁 Conclusions
This project shows how SQL can be used to transform raw job market data into actionable insights. By combining salary information, remote work patterns, and required skills, the analysis gives a clearer view of what employers are looking for in Data Analyst candidates.

Overall, the project demonstrates that data analysis is not just about querying data — it is about uncovering patterns that can guide learning, hiring, and career decisions.
